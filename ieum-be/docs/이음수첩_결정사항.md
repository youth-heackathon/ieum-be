## 1. 서비스 구조

```
                         [보호자 화면 (main)]
                          /            \
                     약 등록     정보 (알러지, 특이사항 등)
                          |
            QR(실물) · 8자리 연결코드
                          ↓
              [임시보호자 or 의료진 화면]
               /                       \
   ① 긴급조회 (의료진)            ② 상세조회 (인계받을 간병인)
   버튼만 누르면 필수정보         보호자가 10분 안에 동의하면
   → 조회자 기기정보 저장          상세 정보 조회
```

| 구분 | 내용 |
| --- | --- |
| 사용자 면 | **두 면**: ① 보호자 ② 임시보호자 또는 의료진(조회하는 쪽) |
| 보호대상자 | 정보로만 존재한다. 서비스 대상일 뿐 **직접 쓰는 화면은 없다** |
| 사용 형태 | 앱 설치 없이 휴대폰 브라우저로 쓰는 웹앱 |
| 고객 | B2C. 서울시·돌봄SOS 연계와 수익 모델은 확장 |
| 운영자 화면 | 0개 |
| 본선 원칙 | 기능을 더하지 않고 줄이고 측정한다 |

## 2. 기술 스택

- 프론트: TypeScript + React, Vercel 배포 (배포 보호 끔)
- 백엔드: Java Spring, 별도 호스팅 (Railway·Render 등)
- DB: Postgres 서울 리전
- 첫날 2시간 안에 두 곳 배포와 CORS 설정을 끝낸다
- AI: Claude(Anthropic)로 정리·처방전 OCR(Opus)·쉬운 말 변환, OpenAI Whisper로 음성 입력
- 약 정보: 식약처 허가정보·e약은요 API, 심평원 의약품표준코드 파일(data.go.kr 15067462)

## 3. 보호자 면

### 3-1. 회원가입·로그인

- 가입 항목: **이름, 전화번호, 생년월일**
- 문자 인증은 모의로 처리한다. 소셜 로그인(구글 등)은 없다
- 체험 모드는 쿠키 세션을 쓴다

### 3-2. 보호자 연결 (여러 명)

- 핵심 보호자가 **초대코드**를 발급하고, 다른 보호자가 그 코드를 입력해 연결한다
- 한 보호대상자에게 보호자를 **여러 명** 연결할 수 있다
- 연결된 보호자 **목록을 조회**할 수 있다
- 초대를 수락하고 동의해야 연결이 성립한다
- *(가정)* 연결된 보호자는 누구든 상세조회 요청을 승인할 수 있다. 보호자 한 명이 쓰러져도 다른 보호자가 승인할 수 있다

### 3-3. 동의

한 화면에서 항목별로 체크한다.

- 개인정보 / 건강정보 / 긴급조회 때 필수정보 공개 / 상세조회 승인 때 상세 정보 제공 / 해외 AI 전송 (Anthropic·OpenAI 명시)
- 보호대상자 본인에게 쉬운 말로 동의를 먼저 받는다. 본인 동의가 불가하고 후견인도 없으면 민감 항목을 제한한다. 대리 동의는 **법률자문 대상**이다

### 3-4. 정보 등록 (알러지, 특이사항 등)

- 입력: 말(Whisper) 또는 글. 체험에서는 "샘플 음성 변환해 보기" 버튼
- AI가 정리하고 **원문 문장을 그대로 인용**한다 → 서버가 원문에서 그 문장을 찾는다 → 숫자·부정어를 검사한다 → 통과 / 확인 필요 / 차단. 검증은 API 호출 없이 규칙으로 한다
- 보호자가 확인해야 저장된다
- 빠진 항목은 되묻는다 (규칙 기반)
- 항목마다 마지막 확인일을 두고, 30일이 지나면 배지를 붙인다
- 항목마다 **긴급조회에 보일지** 보호자가 고른다

### 3-5. 약 등록

- 경로: 처방전(또는 약봉투) 촬영 → 보호자가 주민번호·이름·질병코드를 가림 → OCR(Claude Opus) → 서버가 주민번호 형식을 한 번 더 지움 → 약정보 API 확인 → LLM이 쉬운 말로 정리 + 인용 검증 → 보호자가 직접 고치고 확정
- 가림 단계는 필수다
- 용량은 보호자가 반드시 확인한다 ("0.5알"을 "5알"로 잘못 읽을 수 있음)
- AI는 판단·권고를 하지 않는다 (약사법)
- 약 이름 확인과 자동완성에는 심평원 표준코드를 쓴다. 고위험 약 여부를 표시한다
- 인식 결과는 이름을 가린 사진 위에 하이라이트로 함께 보여 준다
- 약봉투는 감열지라서 받은 날 촬영하도록 유도한다
- 확장 (발표에서만 언급): 건강정보 고속도로, 바코드, 각인 찾기, 나의건강기록 PDF

### 3-6. QR·연결코드 발급

- 보호자 페이지에서 **QR과 8자리 연결코드**를 발급한다
- QR은 **실물**로 출력해 쓴다 (지갑 크기 PDF, 편의점 출력 안내). 현관 부착은 하지 않는다
- *(가정)* 8자리 코드는 QR과 같은 대상을 가리키는 고정 코드다. QR을 찍을 수 없을 때 직접 입력한다. 다시 발급하면 이전 QR과 코드는 무효가 된다
- QR·코드에는 건강정보를 넣지 않는다

### 3-7. 열람 기록·상세조회 승인

- 누가 언제 조회했는지(기기정보) 목록으로 본다
- 상세조회 요청이 오면 연결된 보호자 전원에게 알린다 (실제 문자 없음, 앱 안 알림)

## 4. 임시보호자·의료진 면

*(가정)* 회원가입·로그인 없이 QR을 찍거나 8자리 코드를 입력해 들어온다.

### 4-1. 긴급조회 (의료진)

- "조회하기" 버튼만 누르면 **필수정보**를 바로 본다. 인증·대기는 없다
- 필수정보는 보호자가 긴급조회용으로 고른 항목만이다 (예: 알러지, 약 종류. "혈액을 묽게 하는 약 복용", "페니실린 알레르기")
- 조회하면 **조회자의 기기정보를 저장**하고, 화면에 기록된다는 사실을 알린다
- 위치는 수집하지 않는다 (위치정보법)
- *(가정)* 긴급조회가 일어나면 보호자에게 바로 알린다 (설계 지도의 "조회 즉시 보호자에게 전달"을 따름)

### 4-2. 상세조회 (인계받을 간병인)

- 간병인이 상세조회를 요청하면 보호자에게 알림이 간다
- **10분 안에** 보호자가 동의하면 상세 정보를 볼 수 있다
- 상세 정보: 진정법·복약·특이사항 등 보호자가 남긴 기록과 **원문 인용**, 이름을 가린 약 사진, 고위험 약 표시, 약국 전화, "출처: 식품의약품안전처"
- 상단 고정 문구: "보호자가 적은 돌봄 방법이며 의료 지시가 아닙니다. 마지막 확인: 날짜"
- 요청자 화면은 보호자가 동의하면 "보호자가 확인했어요"로 바뀐다
- *(가정)* 10분 안에 동의하지 않으면 요청이 만료되고, 긴급조회 수준의 정보만 볼 수 있다. 다시 요청할 수 있다

## 5. 심사위원 체험 모드 (배포 URL)

- 노트북에서 처음 여는 심사위원이 설명 없이 끝까지 가야 한다. 체험 모드는 첫날 뼈대와 함께 만든다
- 페르소나: 보호자 박지은(52)과 치매 어머니 (가상 데이터)
- *(가정)* 새 플로우에 맞춘 4단계
  1. **정보 등록**: 말로 남긴 정보를 AI가 정리한다. "AI 실수 끼워 넣기"를 누르면 "원문에 없는 말이라 저장을 막았어요"가 나온다 (검증은 실제로 실행)
  2. **긴급조회**: 의료진이 QR을 찍고 "조회하기"를 누르면 필수정보가 보이고, 보호자 화면에 열람 기록이 뜬다
  3. **상세조회 요청·동의**: 간병인이 상세조회를 요청하고, 보호자가 10분 안에 동의한다
  4. **상세 정보 열람**: 간병인 화면에 보호자가 한 말 그대로, 원문 인용과 함께 보인다. 끝 화면: 처음부터 / 둘러보기 / "40건 중 n건 차단"
- 화면 원칙
  - 휴대폰 두 대(보호자 / 조회하는 쪽)를 나란히 보여 주고, 단계마다 자동 전환
  - 역할 탭 대신 사람 이름을 쓰고, 다음에 누를 버튼 하나만 강조
  - 내부 용어("승인", "1단계")를 쓰지 않는다
  - 화면 속 QR을 폰으로 찍어도 같은 체험으로 이어지고, 2초마다 동기화한다

## 6. 공개 URL 안전장치

1. 첫 화면 고정 안내: 가상 데이터, 실제 정보 입력 금지, 해외 AI(Anthropic·OpenAI) 전송, 24시간 뒤 삭제
2. 주민번호·전화번호·이메일 형식은 서버에서 지운다
3. 연락 버튼에는 "모의" 표시를 붙인다. 실제 문자·112 연결은 없다
4. 입력 원문 로깅을 끈다. 직접 입력은 세션당 5회·IP당 하루 20회·전체 하루 300회, 500자 제한, Anthropic 월 지출 한도
5. 처리방침 링크 한 줄: 수집 항목, 국외 이전 대상, 보관 기간

## 7. 보관·삭제

- 체험 기록: 24시간 뒤 삭제
- 요청자 번호(받는 경우): 30일 뒤 파기
- IP는 해시로 저장

## 9. 만들지 않는 것

- 보호대상자용 화면 (안심 카드 포함)
- 관리자·기관 화면
- 실제 문자·112·119 연동
- 기록 되돌려받기 (확장으로만 언급)

## 10. 발표 문구

| 쓰지 않을 말 | 대신 쓸 말 |
| --- | --- |
| 조회자 특정 | 조회 기록을 남기고 보호자에게 알림 |
| 환각 0% | 40건 중 n건 차단, n건 놓침 |
| 사진은 해외로 안 나감 / 가렸으니 개인정보 아님 | 이름을 가린 뒤 해외 AI로, 동의받고 전송 |
| 가족 동의로 충분 / 법적으로 문제없음 | 대리 동의는 법률자문 대상 |
| 119와 연계 / 구급대원 시스템 연동 | QR을 찍은 의료진이 보호자가 고른 필수정보를 확인 |
| 건강정보 고속도로 연동 / 자녀가 바로 조회 | "나의건강기록 PDF 공유로 넓힐 수 있고, 정부가 치매 보호자 대리 조회를 추진 중입니다" |

그 밖의 금지 표현: 암호화, 무보존 적용, AI가 약 관리
